## 1.7 Q/W Exposure Governance Doctrine

```
Q preserves truth.
W governs exposure.
Public output is not internal truth.
Preservation ≠ publication.
Public restraint ≠ internal deletion.
```

Purpose: prevent Assange-style exposure collapse — where genuine material,
released without exposure governance, triggers platform, legal, political,
identity, or financial counter-operations that destroy the source.

Exposure Gate (Q → W):
Every sensitive Q content must pass through Exposure Gate before entering W.
Questions:
1. Must this be published now?
2. Can it be delayed?
3. Can it be abstracted?
4. Can the subject be de-identified?
5. Can it be reframed as mechanism analysis?
6. Will it expose CCC's judgment chain?
7. Will it trigger platform, legal, identity, or partner risk?
8. Has owner reviewed it?

W expression rules:
```
Mechanism > accusation
Structure > emotion
Historical analogy > direct attack
Abstract model > naming sensitive targets
Low attack surface > high-exposure collision
```

# 4. Intelligence Cycle Protocol｜情报循环协议

**Seven-step closed loop:**

```
1. Direction      — Define the question before collecting material.
                    判断对象 · 时间窗口 · 决策用途 · 风险等级 · 输出形式

2. Collection     — Acquire from: official documents · databases
                    news · academic papers · OSINT
                    satellite/AIS/ADS-B/customs/energy/financial data
                    social media · podcasts · anonymous tips
                    Collection does not replace judgment.

3. Processing     — Transcribe · denoise · deduplicate · segment
                    extract entities · extract timeline · extract causal chain
                    label source type · label fact/inference/judgment/propaganda
                    Unprocessed material does not enter Q core.

4. Analysis       — Distinguish:
                    Fact · Assessment · Inference · Speculation
                    Narrative · Propaganda

5. Production     — Output serves owner decision, not public reading pleasure.
                    Must include: conclusion · confidence · key evidence
                    counter-evidence · unknowns · action recommendation
                    follow-up signals

6. Dissemination  — Q layer: full judgment chain, sources, confidence, sensitive material
                    W layer: filtered public expression only
                    No W contamination of Q.

7. Feedback       — All judgments subject to post-hoc fact-checking.
                    Record: hit/miss · wrong assumptions · failed sources
                    ignored signals · models requiring correction
                    No feedback system = opinion warehouse, not intelligence system.
```

**Three information traps:**
```
1. Information overload  — more material ≠ better judgment
                           Counter: limit scope, limit sources, build signal list
2. Source illusion       — multi-source that all trace to one origin
                           Counter: trace to first source, require independent corroboration
3. Conclusion-first      — system seeks evidence for pre-existing conclusion
                           Counter: competing hypothesis analysis, forced counter-evidence search
```

**Three analysis error-prevention mechanisms:**
```
1. Competing hypothesis analysis — list H1 (main) / H2 (alternative) / H3 (reverse)
                                   Ask: which hypothesis is hardest to rule out?
2. Devil's advocacy              — if this judgment is wrong, where is the error?
3. Pre-mortem analysis           — assume failure in 3 months; work backwards
```
